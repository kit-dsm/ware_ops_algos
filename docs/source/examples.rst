Examples
========

The main example is the getting-started walkthrough. It constructs a small
warehouse directly in Python, shows the domain objects and values, matches
compatible algorithms, assigns article locations, and computes a picker route.

Open the :doc:`getting-started example <getting_started>` in the documentation,
or run the notebook from the repository root:

.. code-block:: bash

   uv run --locked --extra notebook jupyter lab examples/getting_started.ipynb

The notebook is the place to inspect and change the warehouse inputs and see
the resulting visualizations. The separate algorithm-extension example is
documented in :doc:`extending`.
